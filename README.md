# Fake News Classifier

This is a **Machine Learning + NLP (Natural Language Processing)** project for detecting fake news.

⚠️ This project uses **Anaconda (conda environments)** for dependency management.

---

## ⚙️ Setup (Anaconda)

### 1. Install Anaconda

If you don’t have it installed:

https://www.anaconda.com/products/distribution

---

### 2. Create the environment

From the project root directory, run:

```bash
conda env create -f environment.yml
```

This will create the environment with all required dependencies.

---

### 3. Activate the environment

```bash
conda activate nlp_proj_env
```
